# guest C 回归套件的**已知失败基线**（机器可读版；叙述与裁决见 KNOWN-FAILURES.md）
#
# 语义：这里列出的用例文件**预期整体 FAIL**。runner（run-guest-tests.sh）据此判定：
#   - 失败集合 ⊆ 本基线            → 退出 0（打印"已知失败"摘要）
#   - 出现基线外的新失败            → 退出 1（回归）
#   - 基线内的用例**变成通过**      → 退出 1（基线过期，必须同步收紧）
# 最后一条是刻意的：docs/testing.md §四 约定"行为修复时测试会变红，强制同步更新"，
# 否则修好的东西会被基线继续掩盖。
#
# 每行格式：`<用例文件名> [@native|@wine]`（不含路径与扩展名）；
# `#` 起始为注释；空行忽略。可选的模式标注让同一份基线适配两种运行环境。
# 用 WBOX_GUEST_NO_BASELINE=1 可关闭基线判定，回到"任一失败即非零"的原始语义。
#
# ============================================================================
# 2026-07-27：引擎从 blink（C）换成 crates/wbox-linux（纯 Rust）后重定基线。
#
# **这是一次真实的 guest ABI 覆盖回退，不是测试环境问题。** 旧引擎除
# t_net_sockopt@wine 外全绿；新引擎当前 5 通过 / 16 失败。之所以仍然合入：
# 全 Rust 化本身是 PRD §2.2.1 的发布验收条件（旧引擎是 122k 行 C），而
# 补齐 ABI 是 §4.9 F4.R3–R6 明确在跟踪的后续工作。基线如实记录现状，
# 任何**新**回归照样会让门禁变红，任何修好的项也会强制回来收紧这份文件。
#
# 缺口分组（逐条根因见 docs/rust-rewrite.md §4）：
#
#   A. MAP_SHARED 映射不跨进程共享，文件映射也不写回宿主
#      t_exec t_fork_mem
#      fork/execve/wait4 本身已实现（快照式，见 syscall/process.rs），
#      这两个用例剩下的失败全部集中在共享映射：稀疏页表在 fork 时按值
#      深拷贝，MAP_SHARED 区域因此在父子之间断开。
#   B. socket 族与 epoll —— **已实现一半**，两条仍在基线内
#      t_net_epoll t_net_sockopt t_negative
#      AF_UNIX（socketpair / 路径式 bind-listen-connect-accept，含 SOCK_DGRAM）
#      与 epoll（LT/ET/ONESHOT/MOD/DEL/RDHUP/HUP、dup 别名生命周期）已做，
#      由引擎自己实现而不是转给宿主——Windows 上没有 AF_UNIX 的等价物，
#      而 PRD F5 要求两个宿主行为一致。现状：
#        t_net_epoll   111 通过 / 1 失败  —— 唯一剩下的是 D 组那条快照 fork
#                      语义差异（子进程在 fork 返回前就跑完，父进程之后写的
#                      数据它看不到），不是 epoll 本身的缺口。
#        t_net_sockopt 126 通过 / 19 失败 —— 剩下的全是 AF_INET：要真通网就
#                      得接宿主套接字，那是独立的一步（PRD §4.9 L15 第二阶段）。
#      **t_negative 已整条通过并移出基线**（40/0）：socket 的 errno 面补齐后，
#      剩下的全是 rlimit——`setrlimit`/`prlimit64` 的参数校验顺序（先读 new
#      再校验 res，`old` 指针坏掉时新限额**仍然生效**）、以及 RLIMIT_NOFILE
#      软上限真的卡住 fd 分配，且 `pipe`/`socketpair` 失败时要么两个都拿到、
#      要么一个都不留。
#   C. 信号 —— **已实现并整组清空**（t_signalfd 75/0、t_signal_handler 10/0、
#      t_signal_timer 36/0）。
#      投递真的做了：按 x86-64 内核的布局在 guest 栈上构 `rt_sigframe`
#      （pretcode + ucontext + siginfo），把 rip 改到 handler，靠 libc 的
#      SA_RESTORER 走回 `rt_sigreturn` 还原整套寄存器与屏蔽字。投递点在
#      syscall 边界与可中断等待里，于是 `pause`/`nanosleep` 能被
#      `alarm`/`setitimer` 打断并如实回 EINTR。配套补齐了 SIG_IGN 的当场丢弃、
#      execve 的处置复位（handler 复位、SIG_IGN 保留）、`setitimer(NULL)` 解除
#      定时器、`alarm`/`getitimer`，以及 `rt_sigaction` 的四个字段整读整写。
#      剩余缺口写在 syscall/signal.rs 顶部：sigaltstack、SA_RESTART、
#      纯计算循环里的投递点、x87/SSE 状态。
#      **timerfd 已实现并移出基线**（67/0）：到期是**惰性算出来的**，没有后台
#      线程——只记"下次到期的绝对时刻"与周期，在 read/poll/epoll_wait 问起来
#      时拿当前时间回算跨过了几个周期。配套把 poll/epoll_wait 的等待从"一次
#      睡满"改成"边等边复查"：管道/socket 在单线程下确实不会自己变就绪，但
#      timerfd 会（时间在走）。
#      **eventfd 已实现并移出基线**（80/0）：64 位计数器、EFD_SEMAPHORE、
#      一次必须整 8 字节、readv 按总长度散布、pread/pwrite 忽略偏移，
#      以及 poll/epoll（含 EPOLLET 重新武装）与 dup/fork 的计数器共享。
#   D. 快照式 fork 的并发语义差异
#      t_proc —— 子进程在 fork 返回前就跑完了，所以 waitpid(WNOHANG) 不可能
#      看到"还在运行"，父子也无法互相发信号。这是取舍而不是 bug，见
#      syscall/process.rs 顶部的说明。
#   E. mount(2) —— **已实现并整组清空**（t_mount_ro 13/0）。
#      引擎跑在用户态、没有挂载命名空间可用（Windows 宿主上更没有），所以
#      `mount` 落成一条**路径改写规则**：挂载点之下的路径前缀换成源目录。
#      对 guest 不可分辨（它只能通过路径看到结果），而换来的好处是
#      `MS_RDONLY` 能真的生效——只读标记跟着规则走，写类系统调用查一次就
#      知道该不该报 EROFS。
#   F. 文件描述（file description）级共享状态未建模 —— **已修，整组清空**
#      状态标志从"每个 Fd 各存一份 i32"改成一份共享的
#      `Rc<Cell<i32>>`（dup/dup2/F_DUPFD/fork 共享同一个"打开文件描述"），
#      补齐 O_APPEND 写语义、FIONBIO、管道容量与 F_GET/SETPIPE_SZ、
#      管道的 POLLHUP/POLLERR/EPIPE、管道 fsync 报 EINVAL；
#      顺带修掉两个 dirfd 被丢弃的分发错误（faccessat、linkat）与
#      "最小可用 fd 下界写死 3"。t_fd_open 与 t_fd_rw 现已全通并移出基线。
#   G. mmap 的部分精度 —— **已修，整组清空**（t_mmap 140/0 + 5 个故障注入探针）。
#      引擎的内存是自己的稀疏页表，不是宿主 mmap，所以"写到映射里"只改了
#      页表、宿主文件毫不知情，`MAP_SHARED` 的承诺完全没兑现。现在给每段
#      文件映射记账（地址/长度/文件副本/偏移/是否共享），在
#      munmap/msync/mremap/MAP_FIXED 覆盖这些**可观测的时刻**刷回。
#      回写失败要能被 guest 观察到：报 EIO 且映射保持原样，让调用方能重试。
#
# **H 组（宿主 symlink 不防护）已整组清空**：VFS 换成用户态的
# `RESOLVE_IN_ROOT`（逐段解析，符号链接目标重新从 rootfs 根展开），
# `t_sec_path` 与 `t_sec_linkabs` 现已全通并移出基线。
# 四条安全用例（`t_sec_path`、`t_sec_linkabs`、`t_sec_path_abshost`、
# `t_sec_path_relesc`）**全部在基线之外**，任何回归会立刻变红。
# ============================================================================
